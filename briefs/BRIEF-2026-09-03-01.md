## Baseball — paper forward test

**As of 2026-09-03.** Written by the `mlb-paper` session.

<!-- COORDINATOR-STATE
doing: found why the sell rules never fire - a safety check for buying was also switching off selling
left: nothing blocking; from now on this is 5 strategies, not 15

**⚠ You do not have 16 baseball bots. You have 5, wearing 15 names.** Another
window spotted it and I confirmed every number.

**The sell-early rules have fired 3 times in 1,516 bets.** That is 2 in every
1,000. So the "sell early" bots and the "hold to the end" bots have been making
**bit-for-bit identical bets** for a month — 148 shared games for one pair with
not a single difference between them.

**I found the cause and it is a good one.** There is a safety rule that hides
any game which has already started, so a bot can never bet on a game in
progress. **That is right and it stays.** But the same hidden list was being
handed to the selling code — so the moment a game starts, the bot loses sight
of its own bet and can never sell it.

**Which means selling could only ever happen before the game started, and I had
already measured that the price barely moves then** — one cent, over waits of
up to eleven hours.

**How big the gap is:** the same sell rule, replayed over real minute-by-minute
prices *including during the game*, would have fired on **72 of 156 bets**. In
real life it fired on **3 of 1,516**.

**I have deliberately NOT switched it on, and this is a judgment call you can
overrule.** Switching it on means the bots start selling *during* games, and
that is the one thing this project has firm evidence against — your own bot lost
money doing exactly that. **And we already know the answer**: I tested 81
different sell settings on real prices last month, and **every single setting
that used a stop-loss did worse than simply holding.** Turning on in-game
selling to run a test we already have the answer to is a bad trade.

**Two consequences worth knowing.** The good one: picking the best of 15 bots
was really picking the best of 5, so the "best one is probably luck" problem is
smaller than it looked. The bad one: **five of those names were never telling us
anything**, so we did not lose ten strategies today — we found out we never had
them.

**And one honest limit on the whole fleet.** Because so many bots are copies,
the real number of independent bets is **365, not 1,456**. That means the test
can only see a difference of about **5 cents a contract**, and the biggest real
effect ever measured in this project is under 3. **The fleet cannot see what it
is looking for.** That is not a null result — it is a test that is too small,
and I will label it that way from now on.

**Nothing needs you.**
